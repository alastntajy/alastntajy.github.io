AZMAH — النسخة الاحترافية الأولية v3
=====================================

محتويات المشروع:
- index.html      الصفحة الرئيسية.
- admin.html      لوحة إدارة تجريبية للمقالات.
- styles.css      التصميم المتجاوب.
- script.js       البحث والتصنيفات وقراءة المقالات وإدارة المحتوى.
- config.js       اسم المنصة وبريد التواصل.
- README_AR.txt   هذا الدليل.

طريقة التحديث على GitHub Pages:
1. احتفظ بنسخة احتياطية من ملفاتك الحالية.
2. افتح مستودعك على GitHub.
3. ارفع جميع ملفات هذا المجلد إلى جذر المستودع (نفس مستوى index.html).
4. وافق على Commit changes.
5. انتظر اكتمال النشر ثم افتح https://alastntajy.github.io/

مهم جدًا حول لوحة الإدارة:
هذه النسخة تحتوي لوحة أولية على admin.html وتستخدم localStorage في المتصفح.
- افتح https://alastntajy.github.io/admin.html
- يمكنك إضافة المقالات وتعديلها وحذفها وتصدير JSON.
- البيانات تبقى في نفس المتصفح والجهاز فقط.
- المقالات التي تضيفها من لوحة الإدارة لا تُنشر تلقائيًا للزوار ولا تتزامن مع بقية الأجهزة.
- لا توجد مصادقة دخول أو صلاحيات آمنة في هذه النسخة.
- لا تستخدمها لإدارة محتوى حساس أو تعتبرها لوحة إنتاجية عامة.

لجعل لوحة الإدارة حقيقية وآمنة:
نحتاج ربط الموقع بخدمة خلفية مثل Supabase أو Firebase، مع تسجيل دخول للمالك وقواعد صلاحيات تمنع الزوار من التعديل. لا تضع مفاتيح سرية أو كلمات مرور في ملفات GitHub العامة. يجب إعداد ذلك بشكل منفصل قبل فتح لوحة إدارة حقيقية.

إعداد بريد التواصل:
افتح config.js وعدّل contactEmail إلى البريد الذي تريد نشره للزوار:
contactEmail: "your-email@example.com"
أي بريد تضيفه هنا سيكون ظاهرًا في كود الموقع العام. لا تستخدم بريدًا شخصيًا إذا كنت لا تريد نشره.

ملاحظات تحريرية:
المقالات الثلاثة الموجودة أمثلة تجريبية تعليمية، وليست أبحاثًا أكاديمية موثقة. راجعها وأضف مراجع موثوقة قبل تقديمها باعتبارها مادة بحثية.
النطاق azmah.com يحتاج تسجيلًا مستقلًا لدى مسجل نطاقات وقد تكون له رسوم؛ عنوان GitHub Pages مجاني.
