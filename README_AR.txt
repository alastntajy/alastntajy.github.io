# AZMAH.COM — النسخة الأولى

## تخصيص بريدك الشخصي
1. افتح الملف `config.js` باستخدام محرر نصوص.
2. استبدل `ضع_بريدك_هنا@example.com` ببريدك الشخصي، مع إبقاء علامتي الاقتباس.
3. احفظ الملف. لا تكتب كلمة مرور البريد في أي ملف.
4. عند ضغط الزائر على «راسلنا عبر البريد»، سيفتح تطبيق البريد لديه لكتابة رسالة إليك.

مثال:
`const AZMAH_EMAIL = "yourname@example.com";`

## تشغيل الموقع
1. فك ضغط الملف.
2. افتح `index.html` في متصفح الهاتف أو الحاسوب.
3. الملفات المطلوبة يجب أن تبقى معًا في المجلد نفسه: `index.html`, `styles.css`, `script.js`, `config.js`.

## ملكية الموقع وإدارته
- احتفظ بنسخة ZIP والملفات على جهازك.
- أنشئ حساب الاستضافة بنفسك وببريدك، ولا تشارك كلمة المرور أو رمز التحقق مع أي شخص.
- ارفع ملفات الموقع إلى مستودع GitHub خاص بك، ثم فعّل GitHub Pages أو استخدم استضافة ثابتة مجانية.
- حساب الاستضافة والمستودع والبريد المرتبط به يجب أن تكون تحت سيطرتك.
- اسم النطاق `Azmah.com` لا يصبح ملكك بمجرد كتابة الاسم في الموقع؛ يلزم تسجيله لدى مسجّل نطاقات، وقد يتطلب رسومًا سنوية. يمكن البدء بعنوان استضافة مجاني ثم ربط النطاق لاحقًا.
- قد تتطلب بعض الخدمات موافقة أو مساعدة ولي أمر لإتمام إنشاء الحساب أو شراء النطاق.

## محتويات المشروع
- `index.html`: الصفحة الرئيسية.
- `styles.css`: التصميم.
- `script.js`: المقالات والبحث والتصنيفات.
- `config.js`: البريد الذي تختاره للتواصل.
- `README_AR.txt`: هذا الدليل.

## ملاحظات
هذه نسخة أولية ثابتة. المقالات الحالية أمثلة تجريبية وليست أبحاثًا موثقة. لا توجد حتى الآن لوحة تحكم أو قاعدة بيانات أو نظام حسابات. إضافة المقالات حاليًا تتطلب تعديل مصفوفة `articles` في `script.js` ثم إعادة رفع الملفات.
